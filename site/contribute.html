Help improve the classroom

You do not need to be a strong programmer. A clearer sentence, a broken-link report, or a keyboard problem is useful. There is no public contributor community to join, and nothing publishes until Jade reviews it.

Ways to help

  • Open an issue on matchaxmoxie/matchaxmoxie.
  • Say whether it is documentation, accessibility, a lesson error, or a broken link.
  • Do not send student records, passwords, or private class files.
  • Do not assume a licence. This repository does not yet have an approved public licence file.

Fork and pull request is welcome if you already know that flow. Same review rule.

Local preview: clone the repo, then ./scripts/serve.sh. Check pages with node scripts/check-site.mjs.

More detail: CONTRIBUTING.md.
