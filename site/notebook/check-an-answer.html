How do you know when a generated answer is wrong?

A fluent paragraph can still be false. Treat generated text as a draft, not a source.

  1. Run the code. If it does not run, the explanation is unfinished.
  2. Compare names and steps to an official page (Python docs, MDN, GitHub Docs, your syllabus).
  3. Ask what would disprove the claim. If nothing could, the claim is too large.
  4. Keep student work honest: say what you ran and what you still do not know.

On matchaxmoxie, the Python lesson check reads real interpreter output. It will not mark a programme correct because the text looks tidy.
