What is an API, actually?

API means application programming interface. In practice: a menu of requests one programme is willing to answer, plus the exact shape of the question and the reply.

A café counter is a useful picture. You do not walk into the kitchen. You ask for a listed item, in a listed way. The kitchen may change. The counter language stays stable so regulars still know how to order.

On the web, that “order” is often an HTTP request with a documented URL and a JSON reply. Python’s own standard library is also an API: print is a function you call because someone documented what it accepts.

This site’s Python lesson does not call a matchaxmoxie API. It runs in your browser. When you later see “needs an API key,” that usually means a remote service wants proof you are allowed to ask.
