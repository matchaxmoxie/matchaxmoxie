Why a website needs HTML, CSS, and JavaScript

HTML names the parts: heading, paragraph, button, form. Screen readers and search engines read this first.

CSS decides colour, space, and layout. The same HTML can look like a notebook or a poster.

JavaScript reacts: run a quiz, filter a list, load Python in the browser. This classroom site is mostly HTML and CSS. JavaScript is added only where a control needs it.
