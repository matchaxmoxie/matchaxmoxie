What actually happens when you run Python?

You write text. An interpreter reads that text from top to bottom and carries out each instruction it understands. If a line is invalid, it stops and tells you. It does not “know what you meant.”

On this site, the first lesson uses Pyodide: Python compiled to run inside the browser. On your own computer, the same idea is python3 your_file.py. The place changes. The job does not.

Try it: open Python 01, press Load Python, then Run. The output box is the interpreter talking back.
