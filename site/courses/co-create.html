Human + AI Co-Create · portfolio edition

Yes, part of this site is “paste the chaos, get a draft.”

Same spirit as INFO-I 211 Co-Create assignments: a generative chat can shape HTML and copy from whatever you dump in ... syllabus chunks, Canvas announcements, docx exports, team notes. You still own the facts, the tone, and what goes public.

What that means here

  • AI draft: structure, headings, plain-language summary, SEO meta stubs.
  • Human gate: match local files on your Mac, fix names and dates, strip transcript PII, add real links and screenshots.
  • Not allowed: inventing clients, grades, or projects you did not do. If the chat hallucinates, delete it.

Course pages marked with the co-create note in the footer were started from chat-assisted drafts (ChatGPT, or any similar tool you already use for school). The projects (I101 Hamilton campaign, I308 Team 39, etc.) are real; the web page is just packaging.

Workflow you can copy

  1. Export or copy: syllabus learning outcomes + one announcement + your team doc (text only).
  2. Paste into ChatGPT (or your usual generative chat) with the prompt below.
  3. Save the HTML it returns into matchaxmoxie/site/courses/your-course.html.
  4. Re-read every sentence. Swap placeholders for Drive links, images, and names you are allowed to show.
  5. Link the page from index.html. Done.

Starter prompt (paste your course junk underneath)

You are helping me write one portfolio page for my IU Informatics degree (HTML fragment, matcha classroom tone, UK spelling, no em dash). Input: [I will paste Canvas syllabus + announcements + my team notes below.] Output: - <title> and meta description for SEO - One hero: course code, term, one-line lede - Sections: What the class was · What I did (bullets from MY notes only) · Skills I took forward · Artifacts still to add - Do not invent URLs, grades, or teammates. If info is missing, write “Artifacts to add” instead of guessing. - No SSN, student ID, or street address. First names of classmates OK only if already in my paste. My paste starts here:

After you get HTML back, run it through your own eyes (or a friend’s) before publish. Co-create is draft speed, not outsource the truth.
