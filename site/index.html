Question, then try, then revise

Three steps, in beginner language.

  1. Question

    ask What should happen when the name box is empty? and wait

  2. Try

    if answer = then

    say The box is empty. for 2 seconds

  3. Revise

    set name to first name

    An empty answer is a costume with nothing in it. A hyphen does not belong in the name of the box. Change one thing, then run the flag again.

In class, or when someone asks what a button should do: what did you expect, what happened, what would you change?
