Your first GitHub repository

Git remembers versions of files. GitHub hosts those versions on the web so other people (or future you) can see them. You do not need a company job to make a first repository.

Do this once

  1. Create a free GitHub account if you do not have one.
  2. Click New repository. Give it a short English name. Add a README.
  3. Open the README. Write one sentence: what this folder is for.
  4. Commit the change with a short message such as Add a first README.
  5. That commit is now history. You can keep editing.

On your own computer, the same idea is: initialise git, add files, commit, then push to GitHub. The website flow is enough for a first try.

Screens on GitHub change. If a button has moved, follow the official pages, not a screenshot on a blog.
