How to ask for technical help

People can help faster when they can see the same problem you see. You do not need perfect English. You do need the facts.

I am trying to: …
I expected: …
I saw instead: …
I already tried: …
This is on: (browser / Python / assignment name)

Paste the exact error when you have one. A screenshot of a whole desktop is harder to read than the error text.

Office hours exist so you can bring a real question. You are not wasting the hour by being new.

If the question is about this website, open a GitHub issue and use the same template. Jade reviews public issues before anything is published.
