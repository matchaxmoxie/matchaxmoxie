Wix handoff

All handoffs

This page is for the person who will update the live Wix site after the builder leaves.

Handoff means you can sign in, change a page, and publish without the builder sitting there.

Steps

  1. Sign in at wix.com with the email that owns the site.
  2. Open that site's dashboard. Click Edit Site. The first time, the button may say Design Site.
  3. Open the Site pages list from the page name at the top of the editor, then click the page you want.
  4. Click the text, then click Edit Text, and type. If you do not see Edit Text, click the text and type in the box that opens.
  5. Click the picture and use the control that changes it. Upload the new file.
  6. Click Preview if you want to check. Click Publish when the change should go live. A save inside the editor is not the same as Publish.

Button names move a little between editor versions. If a label is not on your screen, stay in the same places: the page list, the text, the picture, and the button that saves or publishes.

Write this down

  • The email that owns the Wix login.
  • The live site address.
  • Who to ask if that email is unknown.
  • Do not write the password on this page.
