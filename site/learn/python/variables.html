Variables aren't as scary as they sound.

A variable is a name that points at a value, so you can use that value later. This page is an independently authored tutorial. The videos that Jade recorded for INFO-I211 Week 1 stay on the I211 page.

  • Beginner
  • No account
  • About 15 minutes

What you will be able to do

  • Say what a variable is, in ordinary language.
  • Assign a value with =.
  • Print a stored value.
  • Change a value and print again.

Prerequisites: none. This is the first Python lesson on this site.

In ordinary language

Think of a labelled jar. The label is the name. What you put inside is the value. Later you can say “open the jar called favorite_tea” instead of repeating the word matcha every time.

In Python, the name goes on the left of =. The value goes on the right. Text values need quotes. A bare word without quotes is treated as another name.

name = "Jade"
favorite_tea = "matcha"
print(name)
print(favorite_tea)

If you change "matcha" to "coffee" and run again, the second line of output should change. The name favorite_tea stays the same. That is the whole point of a variable.

A common mistake

      
Writing tea = matcha without quotes. Python then looks for a variable named matcha. If you never assigned that name, you get NameError. Put quotes around text you want to store as-is.

    


    

      
Knowledge check

      
Practice only. There is no grade, badge, or certificate.

      

        

          1. Which line stores the text Bloomington in a variable called city?
          
          
          
          
Text needs quotes. print only shows a value. It does not store one.

        

        

          2. What does print(name) do if name = "Jade" already ran?
          
          
          
          
print looks up the name and writes the value to output. The variable is still there.

        

        

          3. You write tea = matcha with no quotes. What goes wrong?
          
          
          
          
Without quotes, matcha is a name, not text. If that name was never assigned, Python stops with NameError.
