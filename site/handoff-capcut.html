Six steps

  1. Open CapCut and sign in if it asks.
  2. Start a new project and import the video clips.
  3. Set the frame size to **9:16** for a vertical video.
  4. Trim the clips, order them on the timeline, and add a short caption if needed.
  5. Click **Export** and save the file.
  6. Upload the export where it should be posted and confirm it plays.
