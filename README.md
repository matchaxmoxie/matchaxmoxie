## classroom rules

1. **If you can’t ELI5 it, you’re not done yet.** Plain language so a freshman (or your past self) gets it.
2. **If you don’t understand it, learn it.** Official IU pages win over vibes.
3. **Slow progress is the best progress.** One step today. KISS guides, not hustle checklists.
